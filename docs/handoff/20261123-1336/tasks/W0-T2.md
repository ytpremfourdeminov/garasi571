## Detail Teknis

- Install `@supabase/supabase-js`, `@supabase/ssr`, dan `zod` menggunakan `bun add`.
- Buat `src/lib/supabase.server.ts` berisi `getSupabasePublicClient()` (stateless dengan `SUPABASE_URL` + `SUPABASE_PUBLISHED_KEY` untuk SSR publik/SEO) dan `getSupabaseServerClient()` (`createServerClient` `@supabase/ssr` menggunakan cookie TanStack Start yang menghormati RLS).
- Buat `src/lib/supabase.client.ts` (jika perlu helper tipe/session browser ringan tanpa membocorkan key server).
- Pastikan 100% kompatibel dengan Cloudflare Workers runtime (`nodejs_compat`, tanpa ketergantungan API Node disk/net yang tidak didukung).
