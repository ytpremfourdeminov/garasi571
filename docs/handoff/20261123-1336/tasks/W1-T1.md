## Ringkasan

Implementasikan serving gambar R2 melalui `GET /media/*` (ETag + immutable cache) dan endpoint upload terautentikasi `POST /api/dash/media/upload` khusus subdomain `dash.*`.

## Detail Teknis

- Buat helper `putMediaObject`, `getMediaObject`, `deleteMediaObject`, dan validasi key aman (`cars/...` & `brand/...`, anti path-traversal `..`) di `src/lib/r2.server.ts`.
- Buat route `src/routes/media.$.ts` (`GET /media/$`): baca object dari `MEDIA_BUCKET`, dukung header `If-None-Match` -> `304 Not Modified`, kembalikan `Cache-Control: public, max-age=31536000, immutable` dan `Content-Type` yang tepat.
- Buat `src/routes/api/dash.media.upload.ts` (`POST /api/dash/media/upload`): verifikasi host `dash.*`, verifikasi sesi Supabase (`admin`/`sales`), validasi MIME (`image/webp`, `image/jpeg`, `image/png`) & ukuran maks 5 MB, simpan ke R2, lalu kembalikan `{ r2Key, url, width, height, fileSizeBytes, mimeType }`.
- Jika parameter `carId` dikirim, opsional langsung insert row ke `car_images` atau kembalikan metadata untuk diproses oleh `admin-cars.ts` (rollback R2 jika insert DB gagal).

## Kriteria Selesai (Acceptance Criteria)

- [ ] `GET /media/<valid-key>` mengembalikan status 200 (dan 304 saat `If-None-Match` cocok); key tidak valid mengembalikan 400/404.
- [ ] `POST /api/dash/media/upload` menolak request tanpa sesi staff (401) dan request dari host non-`dash.*` (404/403).
- [ ] File yang diunggah tersimpan di R2 dan langsung bisa diakses via `/media/<key>`.
