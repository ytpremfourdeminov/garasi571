## Detail Teknis

- `src/routes/dash/showroom.tsx` (`dash.*/showroom`): edit nama showroom, kota, alamat, jam operasional, URL Google Maps + preview iframe embed, Instagram handle/URL, upload logo showroom ke R2 (`brand/...`), serta CRUD daftar kontak sales WhatsApp (nama, role, nomor tampil, nomor E164, aktif/nonaktif, urutan). Untuk role `sales`, halaman tampil mode read-only dengan keterangan khusus Admin.
- `src/routes/dash/faqs.tsx` (`dash.*/faqs`): CRUD FAQ, toggle publish/draft, reorder naik/turun, dan dialog konfirmasi hapus.
- `src/routes/dash/team.tsx` (`dash.*/team`): guard `admin`-only di `beforeLoad`, tabel daftar staff (`profiles`), ubah role (`admin`/`sales`), toggle aktif/nonaktif, serta panduan singkat menambahkan akun baru di Supabase Auth.
