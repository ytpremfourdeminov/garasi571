Bangun utilitas kompresi WebP sisi browser (maks 1600px) dan komponen `<CarMediaManager />` untuk upload multi-foto ke R2, tagging sudut wajib riset, set cover, edit alt text, reorder, dan hapus foto.

## Detail Teknis

- Buat `src/lib/image-compress.ts`: gunakan Canvas / `createImageBitmap` untuk mengubah ukuran gambar ke maks 1600px (jaga rasio), ekspor ke `image/webp` kualitas ~0.82, dan kembalikan `{ blob, width, height, fileName }`.
- Buat `src/components/dash/car-media-manager.tsx`: area drag-and-drop & file picker multi-foto, progress bar per file saat upload ke `POST /api/dash/media/upload`, panel **Checklist 6 Sudut Foto Wajib Riset** (`hero`, `eksterior`, `interior`, `odometer`, `mesin`, `dokumen`, plus `minus`).
- Sediakan kontrol per foto: dropdown `angleTag`, tombol 'Jadikan Cover', tombol geser urutan (Naik/Turun), input `alt text` (dengan auto-saran dari nama mobil + sudut), dan tombol Hapus (hapus DB + R2 dengan konfirmasi).

## Kriteria Selesai (Acceptance Criteria)

- [ ] Upload foto JPEG/PNG besar (>3MB) otomatis terkompresi menjadi WebP <= 1600px sebelum dikirim ke Worker.
- [ ] Checklist sudut wajib menyala hijau otomatis saat tag sudut yang sesuai sudah terpasang pada foto.
- [ ] Perubahan urutan, cover, alt text, dan penghapusan foto tersinkron dengan Supabase dan R2.
