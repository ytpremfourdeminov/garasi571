## Detail Teknis

- Pilihan `paymentMode` (`cash-credit` vs `cash-only`), input `cashPrice` (format tampilan rupiah + preview `formatRupiah`), input `creditPrice` & `creditPriceNote` (aktif ketika `cash-credit`), dan toggle `tradeInAvailable`.
- Repeater `creditSimulations`: tambah/hapus/urut paket simulasi dengan field `label`, `provider` (BCA Finance, Hana Finance, dll.), `dp`, `installment` (opsional angka eksak), `installmentLabel` (auto-format dari angka atau custom mis. `Rp5 jutaan`), `tenorYears`, dan `note`.
- Peringatan visual ramah jika `creditPrice >= cashPrice` atau `paymentMode === 'cash-credit'` tapi belum ada simulasi.
