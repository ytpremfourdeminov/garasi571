## Detail Teknis

- Buat `src/lib/host.ts` berisi `isDashHostname(hostname)` (`dash.localhost` atau prefix `dash.`), `getPublicSiteOrigin()`, dan daftar path pass-through (`/_server`, `/api/`, `/media/`, `/assets/`, `/images/`, `/favicon`, `/manifest.json`, `/robots.txt`).
- Perbarui `src/router.tsx` dengan `rewrite: { input, output }`: pada host `dash.*`, eksternal `/` <-> internal `/dash`, `/login` <-> `/dash/login`, `/cars/...` <-> `/dash/cars/...`, dst. Pada host publik, path `/dash*` dan `/admin*` diarahkan ke 404.
- Buat `src/server/auth.ts` berisi server functions: `getCurrentStaffFn`, `loginWithPasswordFn`, `logoutFn`, serta helper server `requireDashHost()`, `requireStaff()`, dan `requireAdmin()`.
- Buat halaman login `src/routes/dash_.login.tsx` (URL eksternal `dash.*/login`, tanpa sidebar layout): cek host `dash.*` di `beforeLoad` (404 jika host publik), redirect ke `/` jika sudah login, form Email & Password berestetika Garasi 571.
- Perbarui `src/routes/robots[.]txt.ts`: jika request datang dari host `dash.*`, kembalikan `User-agent: *
Disallow: /`; jika host publik, pertahankan konfigurasi SEO saat ini.

## Kriteria Selesai (Acceptance Criteria)

- [ ] Pada host publik (`localhost:3009`), membuka `/admin` atau `/dash` mengembalikan 404.
- [ ] Pada host `dash.localhost:3009`, `/login` render halaman login bersih tanpa `/admin` atau `/dash` di URL.
- [ ] Login valid menyimpan cookie sesi Supabase SSR dan `getCurrentStaffFn` mengembalikan profil + role (`admin`/`sales`).
- [ ] `http://dash.localhost:3009/robots.txt` mengembalikan `Disallow: /`.
