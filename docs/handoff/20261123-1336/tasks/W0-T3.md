## Detail Teknis

- Tulis `supabase/migrations/001_init_schema.sql` untuk 7 tabel: `profiles`, `cars` (identitas, spek teknis CC/BBM/bodi/kursi/drivetrain, harga, legalitas terstruktur, `document_checklist`, `inspection_summary`, `imperfections`, `recent_maintenance`, `warranty_info`, `ev_specs`, `video_walkaround_url`, `creator_insights`), `car_images` (dengan `r2_key`, `angle_tag`, `is_cover`, `sort_order`), `car_credit_simulations`, `showroom_settings` (singleton `id = 1`), `sales_contacts`, dan `showroom_faqs`.
- Tambahkan index untuk query katalog (`cars(status, sort_order)`, `cars(is_featured, featured_order)`, `car_images(car_id, sort_order)`, `car_credit_simulations(car_id, sort_order)`) dan trigger `set_updated_at()`.
- Tulis `supabase/migrations/002_rls_policies.sql`: aktifkan RLS di semua 7 tabel, buat fungsi `SECURITY DEFINER` `public.current_staff_role()`, dan terapkan matriks akses `anon` vs `sales` vs `admin` (termasuk `admin` dapat `UPDATE` tabel `profiles` langsung via RLS).
- Terapkan kedua migrasi via MCP `supabase-garasi571-ytpremfourdeminov` (`apply_migration`) dan generate `src/types/database.ts` via `generate_typescript_types`.
