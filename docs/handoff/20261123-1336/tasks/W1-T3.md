## Detail Teknis

- Implementasikan fungsi server murni (untuk dipakai route loader, `sitemap.xml`, `llms.txt`, `llms-full.txt`) sekaligus TanStack Start `createServerFn` wrapper:
- - `fetchPublicShowroom()` / `getPublicShowroomFn`: ambil `showroom_settings` + `sales_contacts` aktif terurut `sort_order`.
- - `fetchPublicCars()` / `getPublicCarsFn`: ambil `cars` dengan `status IN ('ready', 'booked')` (atau opsi `includeSold`) beserta relasi `car_images` (terurut `is_cover desc, sort_order asc`) dan `car_credit_simulations` (terurut `sort_order asc`), dipetakan via `mapDbCarToDomain`.
- - `fetchPublicCarBySlug(slug)` / `getPublicCarBySlugFn`: ambil unit `status IN ('ready', 'booked', 'sold')` + 3 unit serupa.
- - `fetchPublicFaqs()` / `getPublicFaqsFn`: ambil `showroom_faqs` dengan `is_published = true` terurut `sort_order`.
- Tambahkan error handling bersih tanpa membocorkan stack trace database ke publik.
