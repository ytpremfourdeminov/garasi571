## Detail Teknis

- `src/server/dash-cars.ts`: `listDashCarsFn` (semua status + statistik KPI), `getDashCarByIdFn`, `createCarFn`, `updateCarFn` (termasuk sinkronisasi `car_credit_simulations`), `quickUpdateCarStatusFn`, `toggleFeaturedCarFn`, `archiveCarFn` (`sales`+`admin`), `deleteCarPermanentlyFn` (`admin`-only + bersihkan object R2 terkait), `updateCarImagesOrderAndMetaFn`, `deleteCarImageFn` (hapus DB + R2).
- `src/server/dash-showroom.ts`: `getDashShowroomFn`, `updateShowroomSettingsFn` (`admin`-only), `upsertSalesContactFn` (`admin`-only), `deleteSalesContactFn` (`admin`-only), `reorderSalesContactsFn` (`admin`-only).
- `src/server/dash-faqs.ts`: `listDashFaqsFn`, `upsertFaqFn` (`sales`+`admin`), `deleteFaqFn` (`sales`+`admin`), `reorderFaqsFn` (`sales`+`admin`).
- `src/server/dash-team.ts`: `listTeamProfilesFn` (`admin`-only), `updateStaffProfileFn` (`admin`-only: ubah role `admin`/`sales` & `is_active`, dengan guard agar admin terakhir tidak bisa menonaktifkan/demote dirinya sendiri).

## Kriteria Selesai (Acceptance Criteria)

- [ ] Setiap mutasi memvalidasi input menggunakan skema Zod dari `src/lib/domain/schemas.ts`.
- [ ] Role `sales` ditolak (403) pada endpoint `admin`-only (`updateShowroomSettingsFn`, `deleteCarPermanentlyFn`, `dash-team.ts`).
- [ ] Hapus foto/mobil permanen ikut membersihkan file di R2 melalui `deleteMediaObject`.
